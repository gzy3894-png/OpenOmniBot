## 3. Exclude omniinfer for Codex-only slim build?

**Yes — already first-class. Prefer edition flavor `standard`, not a new product.**

Exact switches / tasks:

| Switch | Effect |
|---|---|
| Flavor `standard` (edition) | `LOCAL_MODEL_FEATURE_ENABLED=false`; no `omniinferImplementation` |
| `-Ptarget=lib/main_standard.dart` | Flutter entry without local-model routes |
| Task `:app:assembleDevelopStandardDebug` | Develop + standard + debug |
| Task `:app:assembleProductionStandardRelease` | Slim release |
| `scripts/build-local-release.sh --edition standard` | Release packaging for standard only |
| `scripts/build-local-release.sh --skip-submodules` | Skip omniinfer git init when only standard needed |
| CI already | Only verifies `DevelopStandardDebug` |

**Avoid** bare `./gradlew assemble` / `build` / `test` without a specific module task: `settings.gradle.kts` treats those generic names as requiring omniinfer module presence.

There is **no** separate Gradle property like `-PdisableOmniinfer=true` beyond the **edition flavor** + optional submodule skip. Source sets already split:
- `app/src/standard/...` — stub local-model installer
- `app/src/omniinfer/...` — full OmniInfer managers/channels/assets
