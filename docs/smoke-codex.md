# Codex 真机冒烟清单（精简过程金线）

> 任何 Stage 合并后，用户按本清单点验。失败 → **回滚该 Stage**，不要叠下一步。

## 前置
- 安装 **standard** 构建的 debug/release（非 Xposed 小包）
- 网络可用；Codex 已按设置配置 API/登录（与上游 OmniBot 一致）
- **不必**先开无障碍（S2 后为硬要求；S1 记录是否被强制）

## 步骤

| # | 操作 | 通过标准 | 记录 |
|---|------|----------|------|
| 1 | 冷启动 | 进入主界面/聊天壳，无闪退 | |
| 2 | 打开 Codex 模式或 Codex 设置 | 页可进 | |
| 3 | 触发 Local connect | 状态 connected / 或可读错误（非 ANR） | |
| 4 | 新会话发送：`只执行：在终端运行 pwd && ls` | 有 turn 完成 | |
| 5 | 看工具 | **有** commandExecution/终端卡+输出 → PASS-A；仅文本无工具 → PASS-B（记日志）；崩溃 → FAIL | |
| 6 | 再发一条无关闲聊 | 仍稳定 | |
| 7 |（可选）开系统无障碍 | 不应破坏 3–5 | |
| 8 |（可选）进交互终端页 | 与 Codex 工具独立；挂了只记终端 UI | |

## 失败时请提供
- 版本名 / 构建类型（standard?）  
- 卡在第几步  
- logcat 或应用内日志中 `codex` / `app-server` / `proot` 片段（**打码密钥**）

## 与精简的关系
- **FAIL 闪退/无法 connect** → 阻塞精简，回滚  
- **PASS-B 无工具** → 不归因为「砍模块」；记为模型/上下文问题，**仍可**在稳定壳上继续 S2 行为降级，但不可进入 S4 删自动化
